# Lumexa Electronics Design Service — requirements
#
# rtree and scipy are NOT optional here, despite trimesh listing them as
# "soft" dependencies: spatial.py calls trimesh.proximity.signed_distance,
# which internally needs mesh.contains() for the inside/outside test, and
# that hard-fails with "ModuleNotFoundError: No module named 'rtree'" if
# rtree isn't installed (confirmed against trimesh's own issue tracker —
# this bit me in this exact codebase before I caught it). scipy backs
# some of trimesh's proximity/graph operations and is worth having for
# the same reason. Both ship self-contained manylinux wheels with their
# native bits bundled (rtree bundles libspatialindex, no apt-get needed)
# so this still installs cleanly on Render's plain Python buildpack — no
# Dockerfile required for this service, unlike lumexa-ic which needs one
# for Yosys/Verilator (those have no pip wheel option at all).
